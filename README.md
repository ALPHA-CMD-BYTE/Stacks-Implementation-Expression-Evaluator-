## Requirements

Python 3.8 or newer. No external libraries.

## How to run

1. Put `stack_evaluator.py` and `input.txt` in the same folder.
2. Open a terminal in that folder and run:

```bash
python stack_evaluator.py
```

3. Results are written to `output.txt` and printed on screen.

To use other file names:

```bash
python stack_evaluator.py test_input.txt test_output.txt
```

## Input format

One expression per line. Expressions are separated by a line containing only a
separator such as `-----`.

```
3 + 5 * 2
-----
(8 / 4) + 7 * 2
-----
10 - (2 + 3) * 4
```

## Output format

Each expression is replaced by its result, and the separator lines are kept
exactly as in the input:

```
13
-----
16
-----
-10
```

## How it works

1. `Stack` class: `push`, `pop`, `peek` (plus `is_empty`, `size`).
2. `evaluate_expression()` uses two stacks, one for operands and one for operators.
   It respects precedence (`*` and `/` before `+` and `-`), left-to-right
   evaluation, and parentheses.
3. `process_file()` reads `input.txt`, evaluates each expression, copies the
   separator lines, and writes `output.txt`.

## Assumptions and limitations

- Supported operators: `+  -  *  /`, parentheses `( )`, spaces optional.
- Numbers may be integers or decimals; unary minus is supported (`-5 + 3`, `2 * (-3)`).
- Whole-number results print without `.0` (e.g. `13`); other results are
  rounded to 6 decimal places (e.g. `2.5`).
- `/` is true division, so `7 / 2` gives `3.5`.
- Invalid expressions do not crash the program; the output line shows a message
  such as `Error: division by zero` or `Error: mismatched parentheses`.
- Blank lines are ignored. Powers (`^`), modulo and functions are not supported.
- Note: the sample output in the assignment sheet shows `17` for
  `(8 / 4) + 7 * 2`; the mathematically correct value is `2 + 14 = 16`,
  which is what this program outputs.
